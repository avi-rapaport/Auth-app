# Auth App

## runing instructions

### Backend

- Open terminal window
- cd ./backend
- node --watch app.js

### Frontend

- Open anouther terminal window
- cd ./frontend
- npn run dev

### Notes

I preferred using the TanStack library because I find it more convenient, but I still implemented the custom `useFetch` hook—both to demonstrate my command of `useEffect` (as per the instructions) and because it helped me prevent manual access to user details without a token.
